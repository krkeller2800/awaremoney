# Fake Statement Snapshot Name Extraction Fix

## Summary of Issue
Fake statement PDFs generated by the `FakePDFGen` tool were importing into the main app without their corresponding institution name (e.g., leaving the field blank/nil). 

There were two underlying causes:
1. **Vertical Misalignment**: The issuer name (e.g., `"Northstar Credit Union"`) and the `"Statement"` keyword in the header were drawn at different Y-coordinates (a 6-point vertical difference). This caused PDFKit text extraction to group them into separate lines, preventing the parser from matching suffix-based patterns.
2. **Unknown Institution Name**: Fictional institutions (like `"Northstar Credit Union"`) do not exist in the app's predefined `knownInstitutions()` list, and the generated statement did not contain any domain URL to fall back on for dynamic extraction.

---

## Technical Solution (Tool-Only)
To solve the issue entirely within the tool (keeping the application target parser changes reverted), two changes were made to [FakeStatementPDFRenderer.swift](file:///Volumes/XcodeSSD/Users/karldev/Documents/DebtScope/Tools/FakePDFGen/Sources/FakePDFGen/FakeStatementPDFRenderer.swift):

### 1. Vertical Alignment
Aligned both the issuer name and the `"Statement"` header text to the exact same Y-coordinate:
```swift
drawText(recipe.issuerName, in: CGRect(x: margin, y: pageRect.height - 88, width: 280, height: 32), attributes: .title())
drawText("Statement", in: CGRect(x: pageRect.width - margin - 170, y: pageRect.height - 88, width: 170, height: 32), attributes: .rightTitle())
```
This forces PDFKit to extract `"Northstar Credit Union Statement"` as a single line, maintaining correct structure.

### 2. Domain URL Heuristic Rendering
Added dynamic domain URL generation and rendering in the header (aligned horizontally with the page numbers):
```swift
let domainLabel = recipe.issuerName.lowercased()
    .replacingOccurrences(of: " ", with: "-")
    .replacingOccurrences(of: "&", with: "-and-")
    .filter { $0.isLetter || $0.isNumber || $0 == "-" }
let domainURL = "www.\(domainLabel).com"
drawText(domainURL, in: CGRect(x: margin, y: pageRect.height - 108, width: 280, height: 18), attributes: .body())
```
* **How it works with the unmodified app**: The app's `StatementIntakeClassifier.detectInstitutionFromDomain(lines:)` scans the first 120 lines for a domain matching the regex `(?i)\b(?:https?://)?(?:www\d*\.)?([a-z0-9-]{3,})\.(com|net|org|bank|loan|mortgage|finance|financial|credit)\b`. It captures the label `northstar-credit-union`, ignores common domain parts, and formats it back to capitalized words: `"Northstar Credit Union"`.
